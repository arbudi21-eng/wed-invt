4 Story

One line per story photo. Each line becomes the caption and text for that carousel slide. Leave blank to use the design's defaults.

5 Media

Photos are embedded as data URIs — keep each under ~500 KB for a manageable ZIP. Music must be under 3 MB.

6 Supabase

Use the anon (public) key — never the service_role key. The key is embedded in the generated site and will be visible to guests. Create a free project at supabase.com and run the included SQL to set up RSVP and wishes tables.

Project URL is optional - the system will use default settings if left blank.

7 Link

Your unique wedding link will be available once you download the site.

Suffix is 6-character base32, can't be guessed. Links sent to guests use this URL.
